# UNITY RUST — публічний сайт (без БД і RCON)

Безпечна публічна версія сайту: **без SQLite, без RCON, без секретів**.
Скарги живуть у пам'яті й дублюються в Discord.

## Що працює

- головна, правила, новини, контакти
- **статистика онлайн** — реальні гравці з Rust-сервера (UDP A2S, без RCON)
- **лідерборд** — якщо заданий `PLAYERS_FILE` (інакше порожній)
- **голосування за наступну мапу** — без Steam-входу, один голос на браузер;
  стартові варіанти й картинки лежать у `maps.default.json` та `images/maps`
- **скарги** — файл доказу та посилання на відео обидва необов'язкові;
  кожна скарга йде в Discord
- **бот підтримки** — запускається разом із сайтом, якщо заданий
  `SUPPORT_BOT_TOKEN`; тикети, скарги, логи, бета-заявки
- щоденний звіт у Discord (якщо налаштований Discord)

## Що в розробці (навмисно вимкнено)

- магазин
- заявки в стаф
- вхід через Steam
- кабінет, історія покупок, «Мої прив'язки»

Ці сторінки відкриваються, але показують «В РОЗРОБЦІ» або повідомлення,
що функція тимчасово недоступна.

## Render (безкоштовно)

1. Завантаж вміст архіву в GitHub-репозиторій.
2. Render → **New → Web Service** → підключи репозиторій.
3. Налаштування:

| Параметр | Значення |
|---|---|
| Runtime | Node |
| Build Command | `npm install --omit=dev` |
| Start Command | `node server.js` |
| Health Check Path | `/healthz` |

4. **Environment**:

| Змінна | Значення |
|---|---|
| `NODE_ENV` | `production` |
| `SITE_MODE` | `public` |
| `NODE_VERSION` | `24` |
| `SERVER_QUERY_HOST` | `5.199.232.192` (або адреса UDP-тунелю) |
| `SERVER_QUERY_PORT` | `28017` |
| `DISCORD_WEBHOOK_URL` | необов'язково — скарги та звіт у Discord |
| `SUPPORT_BOT_TOKEN` | токен бота підтримки (окремий Discord-застосунок) |
| `DISCORD_GUILD_ID` | ID Discord-сервера для бота підтримки |
| `STAFF_ROLE_ID` | ID ролі(ей) стафу, можна через кому |
| `PUBLIC_BASE_URL` | необов'язково — `https://твій-сайт.onrender.com` |

Замість вебхука можна дати боту: `DISCORD_BOT_TOKEN` + `DISCORD_GUILD_ID`
(+ `DISCORD_CHANNEL_ID`, якщо треба конкретний канал).

5. Deploy.

## Інший Node-хостинг

- Start Command: `node server.js`
- Порт береться зі змінної `PORT`, сайт слухає `0.0.0.0`.
- Потрібен **Node.js 24**.

## Онлайн без RCON

Сайт робить UDP-запит `A2S_INFO` на query-порт Rust-сервера
(`SERVER_QUERY_HOST:SERVER_QUERY_PORT`, типово `28017`). Якщо сервер
вимкнений або UDP закритий — показується «невідомо», сайт не падає.

Якщо Rust-сервер за playit.gg/іншим тунелем, зроби **окремий UDP-тунель
на порт 28017** і встав його публічну адресу в `SERVER_QUERY_HOST` /
`SERVER_QUERY_PORT`. Без відкритого UDP 28017 онлайн буде «невідомо».

## Бот підтримки

`server.js` запускає `support-bot/ticket-bot.js` дочірнім процесом, якщо
в оточенні є `SUPPORT_BOT_TOKEN`. Це окремий Discord-застосунок
`Unity rust support`, він не конфліктує з сайтовим ботом
`DISCORD_BOT_TOKEN`.

- токен і ID сервера задаються тільки в Environment хостингу;
- `/healthz` показує `supportBot: true`, коли процес живий;
- при падінні бот автоматично перезапускається;
- `KEEPALIVE_URL` або автоматичний `RENDER_EXTERNAL_URL` не дає
  безкоштовному Render-сервісу заснути;
- тикети зберігаються у `support-bot/data`, на free-хостингу це тимчасово;
  для постійного зберігання задай `SUPPORT_BOT_DATA_DIR` на persistent disk.

## Чого немає

- постійної БД — історія скарг очищається після рестарту
- RCON — жодних команд на сервер із сайту
- входу через Steam
- адмінки без `ADMIN_PASSWORD`
- кабінету власника без `OWNER_STEAM_ID`

## Безпека

- секретів у файлах немає
- `/server.js`, `/package.json`, `/data/*` недоступні по прямих посиланнях
- CSP, `X-Frame-Options: DENY`, rate limit, білий список статики
- завантаження файлів обмежене 60 МБ і білим списком розширень
